# 07 Change Log & Decision Records

History of meaningful changes to AI-SDLC and the decisions that explain why the framework evolved.

Use this area for both architectural and process decisions. Not every decision is an ADR in the strict architectural sense.

Examples:

* Test intent must be accepted before agent implementation.
* R0 may use a lightweight review path.
* Higher-risk releases require tested recovery/rollback strategy.
* E2E automation is selective rather than 1:1 with manual test cases.

## Suggested record format

* Date
* Decision
* Context
* Options considered
* Outcome
* Rationale
* Consequences
* Related AI-SDLC pages

## Status

Structure created; decision records will be added as the framework becomes formalized.
